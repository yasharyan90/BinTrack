## 3. Key implementation notes

### 3.1 Realtime invalidation map
| Table change | Invalidate queries |
|---|---|
| `stock_levels` (product_id, bin_id) | `['product', product_id]`, `['bin', bin_id]`, `['search']`, `['dashboard']` |
| `alerts` | `['alerts']`, `['alerts','unread']` + toast if severity critical & new |
| `pick_tasks` (order_id) | `['order', order_id]` |
| `orders` | `['orders']`, `['dashboard']` |
| `stock_movements` | `['movements']`, `['dashboard','recent']` |
| `import_jobs` (id) | `['import', id]` |

### 3.2 Scanner integration
```ts
// lib/scanner.ts (sketch)
import { BrowserMultiFormatReader } from '@zxing/browser'
export async function startScan(video: HTMLVideoElement, onDecode: (text: string) => void) {
  const reader = new BrowserMultiFormatReader()
  const controls = await reader.decodeFromVideoDevice(undefined, video, (result) => {
    if (result) { navigator.vibrate?.(80); onDecode(result.getText()) }
  })
  return () => controls.stop()
}
// HID scanners: listen on window keydown, buffer chars typed < 50 ms apart, flush on Enter.
```
Bin QR payload = `location_code` (plain text, e.g. `WH1-R02-B017`). Product barcode = EAN-13 / Code128 of `products.barcode`; SKU also accepted.

### 3.3 RPC error mapping
`error.message` looks like `INSUFFICIENT_STOCK:Only 3 available in WH1-R01-B004`. `lib/errors.ts` splits on first `:`; known codes map to friendly titles; unknown → generic with message.

### 3.4 Type generation
`npm run gen:types` → `supabase gen types typescript --local > src/types/database.ts`. Use `Database['public']['Functions']['search_products']['Returns']` for RPC typing.

### 3.5 Optimistic pick confirm
Mutation `confirm_pick` → optimistic set task status `picked`; on error rollback + toast; on success realtime confirms.

## 4. Risk register

| Risk | Impact | Mitigation |
|---|---|---|
| iOS Safari camera quirks (autoplay, permission) | scanning fails on iPhones | `playsinline`, user-gesture start, manual input fallback, HID support |
| Realtime free-tier connection limits | live updates drop | one socket per client, unsubscribe on unmount, polling fallback |
| Concurrent allocation oversells | wrong promises | `FOR UPDATE SKIP LOCKED` + reserved_qty + pgTAP concurrency test |
| Large CSV timeouts in Edge Function (150 s limit) | import fails | chunk of 200 rows per RPC; resume from `processed_rows` |
| JWT role staleness after role change | stale permissions | `auth_role()` reads `profiles` (source of truth), not only JWT |
| pg_cron unavailable locally | time-based alerts stale | `evaluate_alerts()` also runs per movement; document manual call |
| Trigram false positives | noisy search | rank barcode/SKU exact first; threshold 0.25 |
